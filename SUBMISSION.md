# Hackathon Submission Notes — CloudPath AZ-900 Learning Companion

## Project summary

**CloudPath** is an unofficial AZ-900 learning companion shaped by a learner's own Microsoft Learn journey. It aims to reduce navigation confusion by turning the learning path into a clear sequence of units, with plain-language lessons, school-based analogies, flashcards, original practice questions, and a practical Azure subscription and cost exploration lab.

## Problem

A learner can complete Microsoft Learn units but still struggle to see the full learning roadmap, connect concepts to familiar situations, test understanding unit by unit, and track what needs revision.

## Proposed solution

CloudPath organizes a module into five units and connects each lesson to revision resources:
- Unit 1: orientation and roadmap.
- Unit 2: cloud computing explained through the school's on-premises server.
- Unit 3: shared responsibility through the school's cloud student-record system.
- Unit 4: public, private, and hybrid cloud models.
- Unit 5: consumption-based costs, Azure hierarchy, simulated portal, and a safe practical lab.

Revision resources include Unit 1 flashcards, flashcards for Units 2–5, and original practice questions for Units 2–5.

## Demo sequence (about 2 minutes)

1. Open the repository README and show the five-unit roadmap.
2. Open Unit 2 and explain how the school moves from an on-premises server to cloud services.
3. Open Unit 3 or Unit 4 to demonstrate that the school scenario connects the concepts across units.
4. Open the Unit 2–5 flashcards and show the prompt/answer format.
5. Open the practice question bank and show the scenarios and explanations.
6. Open Unit 5 to show the Azure hierarchy, simulated portal, consumption example, and safe practical lab.
7. Close by explaining the next product-development step: an interactive interface with per-unit progress, answer feedback, and a revision dashboard.

## What exists in this repository

- Five lesson drafts for Module 1.
- Unit 1 flashcards.
- Flashcards for Units 2–5.
- Practice questions for Units 2–5.
- A practical Azure subscription and cost exploration lab.
- README with navigation and the project's current scope.

## Honest current limitations

The repository currently contains Markdown learning content. It is not yet a fully interactive web app. Persistent progress tracking, a live AI tutor, automatic quiz scoring, and a real Azure billing integration have not been implemented in this repository. The Azure portal shown in Unit 5 is explicitly a teaching simulation, not a live account or real bill.

## Safety, originality, and accuracy

- This is an unofficial learning project, not a Microsoft product.
- Questions are original learning questions and are not copied from real certification exams.
- Real Azure account eligibility, free offers, prices, and billing depend on current Microsoft terms and the learner's account.
- Learners should use an approved account or sandbox, review prices before deployment, and clean up lab resources.
- Microsoft's current AZ-900 certification page and skills outline remain the authority for exam scope.
