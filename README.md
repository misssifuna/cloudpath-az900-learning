# CloudPath AZ-900 Learning Companion

An unofficial, learner-built companion to the Microsoft Azure Fundamentals (AZ-900) journey. It combines a guided roadmap, plain-language lessons, original practice questions, flashcards, and a practical Azure cost-management lab.

> **Disclaimer:** This is an independent learning project, not an official Microsoft product. It does not reproduce real exam questions. Check Microsoft's current AZ-900 skills outline for authoritative exam objectives.

## Suggested learning loop
1. Follow the units in order.
2. Explain each concept in your own words using the school scenario.
3. Review flashcards before looking at answers.
4. Answer practice questions and read explanations.
5. Complete the Unit 5 Azure portal lab only in an approved account or sandbox; review pricing and clean up resources.
6. Revisit concepts you answered incorrectly.
