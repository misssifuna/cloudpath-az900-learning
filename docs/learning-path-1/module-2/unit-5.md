# Learning Path 1 — Module 2, Unit 5: Describe the benefits of manageability in the cloud

**Learning path:** Introduction to Cloud Infrastructure — Describe cloud concepts  
**Module:** Describe the benefits of using cloud services  
**Learning goal:** Explain how cloud tools can make resources easier to deploy, monitor, and administer.

Cloud manageability includes the ability to provision resources, monitor their health, apply updates, automate repetitive tasks, and manage access through consistent tools. Cloud services can reduce some infrastructure work, but the organization still needs processes, permissions, monitoring, and trained people.

For a school website, a managed hosting platform may handle parts of the underlying infrastructure while staff focus more on the website and its content. A virtual machine offers more control but generally requires more operating-system administration.

## Quick knowledge check
**Which approach usually requires less operating-system maintenance: a managed web hosting platform or a self-managed virtual machine?**

**Answer:** A managed web hosting platform, although application and configuration responsibilities remain.
