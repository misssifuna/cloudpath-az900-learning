# Learning Path 1 — Module 2, Unit 1: Introduction to the benefits of cloud services

**Learning path:** Introduction to Cloud Infrastructure — Describe cloud concepts
**Module:** Describe the benefits of using cloud services  
**Learning goal:** Preview how cloud services can help organizations build resilient, secure, manageable systems.

Cloud services are not valuable simply because they run in a provider's datacenter. They offer capabilities that can help an organization scale, recover from failures, improve security and governance, and manage systems more efficiently.

Imagine a school website that becomes busy during admissions. The school needs the site to stay available, respond to changing demand, protect records, and be manageable by a small IT team. This module explores these benefits and sustainability considerations.

## Quick knowledge check
**Name one benefit a school might seek from cloud services.**

**Answer:** Examples include scalability, reliability, security, manageability, or improved resilience.
