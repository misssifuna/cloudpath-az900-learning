# Learning Path 1 — Module 2, Unit 2: Describe the benefits of high availability and scalability in the cloud

**Learning path:** Introduction to Cloud Infrastructure — Describe cloud concepts
**Module:** Describe the benefits of using cloud services  
**Learning goal:** Distinguish high availability from scalability and explain why both matter.

**High availability** means designing a service to remain accessible for an expected proportion of time, including when some components fail. Redundancy, health monitoring, and resilient design can contribute to availability.

**Scalability** is the ability to adjust capacity to changing demand. Scaling out adds instances; scaling in removes instances. Scaling up increases the resources of an instance; scaling down reduces them.

A school admissions portal may need extra capacity during enrollment. Scaling helps handle a surge; availability design helps keep the service accessible when a component fails. Neither term means that outages are impossible.

## Quick knowledge check
**The admissions portal adds more application instances when traffic rises. What is this an example of?**

**Answer:** Scaling out, a form of horizontal scaling.
