# Learning Path 1 — Module 2, Unit 6: Describe sustainability considerations in the cloud

**Learning path:** Introduction to Cloud Infrastructure — Describe cloud concepts  
**Module:** Describe the benefits of using cloud services  
**Learning goal:** Recognize how cloud usage choices can influence energy use and sustainability.

Cloud providers can operate large datacenter fleets and invest in efficiency and sustainability initiatives. However, moving a workload to the cloud does not automatically make it sustainable. The workload's design, resource sizing, utilization, storage retention, and data movement all matter.

Practical considerations include avoiding idle resources, right-sizing capacity, choosing appropriate storage tiers, deleting unneeded data in line with retention requirements, and reviewing provider sustainability information. Do not sacrifice reliability, security, or legal retention needs simply to reduce resource use.

## Quick knowledge check
**What is one action that can improve resource efficiency?**

**Answer:** Turn off or remove unused resources, right-size capacity, or avoid retaining unnecessary data.
