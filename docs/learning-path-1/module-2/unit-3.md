# Learning Path 1 — Module 2, Unit 3: Describe the benefits of reliability and predictability in the cloud

**Learning path:** Introduction to Cloud Infrastructure — Describe cloud concepts
**Module:** Describe the benefits of using cloud services  
**Learning goal:** Explain reliability and predictability as distinct cloud benefits.

**Reliability** is the ability of a system to perform as expected and recover from failures. It is supported by architecture, redundancy, backup and recovery planning, monitoring, and tested procedures.

**Predictability** means being able to estimate and understand system performance and costs under expected conditions. Monitoring trends, setting budgets, testing capacity, and reviewing usage help improve predictability.

For a school portal, reliability concerns whether users can continue to access essential services; predictability concerns whether the team can plan expected performance and expenditure. A cloud provider does not automatically make an application reliable: design and operations still matter.

## Quick knowledge check
**A team studies usage trends to estimate next term's hosting bill. Which benefit is it improving?**

**Answer:** Predictability, especially cost predictability.
