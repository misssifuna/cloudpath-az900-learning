# Learning Path 1 — Module 2, Unit 4: Describe the benefits of security and governance in the cloud

**Learning path:** Introduction to Cloud Infrastructure — Describe cloud concepts
**Module:** Describe the benefits of using cloud services  
**Learning goal:** Describe how cloud security capabilities and governance controls help protect resources.

Cloud providers invest in physical security and platform protections, and offer tools for identity, access control, encryption, monitoring, and policy enforcement. Customers still need to configure services correctly, protect credentials, manage permissions, and secure their data and applications according to the shared responsibility model.

**Security** focuses on protecting systems and information. **Governance** helps ensure resources follow organizational rules, standards, and requirements. For example, a school might restrict who can access student records and require resources to be deployed only in approved regions.

## Quick knowledge check
**Does using a cloud provider remove the customer's responsibility to manage user permissions?**

**Answer:** No. Responsibilities are shared and depend on the service and configuration.
