# Learning Path 1 — Module 3, Unit 2: Describe Infrastructure as a Service (IaaS)

**Learning path:** Introduction to Cloud Infrastructure — Describe cloud concepts  
**Module:** Describe cloud service types  
**Learning goal:** Explain what IaaS provides and what the customer still manages.

**Infrastructure as a Service (IaaS)** provides fundamental computing resources such as virtual machines, networking, and storage. The provider operates the underlying physical infrastructure, while the customer has significant responsibility for the operating system, installed software, configuration, data, and access controls.

A school might choose a virtual machine when it needs control over the operating system or must run software that is not supported by a more managed platform. That flexibility also means more maintenance work, such as updates, hardening, and monitoring.

## Quick knowledge check
**Who normally manages the guest operating system on an IaaS virtual machine?**

**Answer:** The customer, while the provider manages the underlying physical infrastructure.
