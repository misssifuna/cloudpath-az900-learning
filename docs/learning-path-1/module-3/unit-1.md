# Learning Path 1 — Module 3, Unit 1: Introduction to cloud service types

**Learning path:** Introduction to Cloud Infrastructure — Describe cloud concepts  
**Module:** Describe cloud service types  
**Learning goal:** Preview the differences between IaaS, PaaS, and SaaS.

Cloud services can provide infrastructure, a managed platform for building applications, or complete software accessed by users. These models differ in how much the customer manages and how much the provider operates.

This module compares Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS). The key is not to memorize labels alone: identify the workload and the amount of control or administration the organization needs.

## Quick knowledge check
**Which service model usually provides a complete application for users to access?**

**Answer:** Software as a Service (SaaS).
