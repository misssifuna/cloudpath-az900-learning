# Learning Path 1 — Module 3, Unit 4: Describe Software as a Service (SaaS)

**Learning path:** Introduction to Cloud Infrastructure — Describe cloud concepts  
**Module:** Describe cloud service types  
**Learning goal:** Explain what SaaS provides and recognize its typical customer/provider responsibility split.

**Software as a Service (SaaS)** provides a complete application that users access, commonly through a browser or app. The provider operates the application and underlying platform, while the customer typically manages users, access settings, data use, and organization-specific configuration.

A school using an online email or collaboration service is using a SaaS-style offering. SaaS usually requires the least infrastructure management of the three service models, but the organization must still manage identity, permissions, data handling, and compliance needs.

## Quick knowledge check
**Which service model usually offers a complete application ready for users?**

**Answer:** Software as a Service (SaaS).
