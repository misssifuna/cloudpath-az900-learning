# Learning Path 1 — Module 3, Unit 3: Describe Platform as a Service (PaaS)

**Learning path:** Introduction to Cloud Infrastructure — Describe cloud concepts  
**Module:** Describe cloud service types  
**Learning goal:** Explain what PaaS provides and how it reduces infrastructure management compared with IaaS.

**Platform as a Service (PaaS)** provides a managed environment for developing, deploying, and running applications. The provider manages more of the underlying platform, while the customer focuses on application code, data, and application configuration.

A school might use a managed web app platform to host its admissions portal without managing the operating system of a virtual machine. PaaS can reduce operational work, but it does not remove the customer's responsibility for application security, identity, data, or appropriate configuration.

## Quick knowledge check
**In a PaaS model, what can developers focus on more directly than in IaaS?**

**Answer:** Application code and data, while the provider manages more of the underlying platform.
