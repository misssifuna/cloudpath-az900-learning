# Learning Path 1 — Describe cloud concepts

**Primary syllabus reference:** [AZ-900 Badge Links Reference](../AZ-900-BADGE-LINKS-REFERENCE.md)

CloudPath uses **five app units** in Module 1. The supplied reference lists six source entries because it separates “Introduction to cloud computing” and “What is cloud computing?” CloudPath intentionally combines those overlapping topics in Unit 2 while retaining the source wording in the reference file.
