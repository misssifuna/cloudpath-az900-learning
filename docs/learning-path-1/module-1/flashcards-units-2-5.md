# Module 1 Flashcards — Units 2–5

Use these like decorated index cards: read the **Front**, answer from memory, then read the **Back**.

## Unit 2 — Introduction to cloud computing
### Card 2.1
**Front:** What is cloud computing?
**Back:** Delivery of computing services—such as servers, storage, databases, networking, and software—over a network, usually the internet.

### Card 2.2
**Front:** What is an on-premises server?
**Back:** A physical server located at an organization's premises and operated by the organization or its IT provider.

### Card 2.3
**Front:** What is the key difference between on-premises hosting and cloud computing?
**Back:** With on-premises hosting, the organization operates its own physical server. With cloud computing, it uses services supplied by a cloud provider that operates the underlying infrastructure.

### Card 2.4
**Front:** Name four basic computing resources.
**Back:** Processing power, memory, storage, and networking.

### Card 2.5
**Front:** Does Wi-Fi alone mean a computer is using cloud computing?
**Back:** No. It must use a computing service delivered by a provider over a network.

## Unit 3 — Shared responsibility model
### Card 3.1
**Front:** What does the shared responsibility model describe?
**Back:** How security and management responsibilities are divided between a cloud provider and its customer.

### Card 3.2
**Front:** Who normally manages the physical security of a cloud provider's data centre?
**Back:** The cloud provider.

### Card 3.3
**Front:** Who should manage which school staff can access student records?
**Back:** The school, using the service's identity and access controls.

### Card 3.4
**Front:** Moving from IaaS to PaaS to SaaS generally changes what?
**Back:** The provider manages more of the underlying technology stack as the service becomes more managed.

### Card 3.5
**Front:** Does cloud adoption remove every customer security responsibility?
**Back:** No. The customer still manages responsibilities such as identities, permissions, data, and customer-controlled settings.

## Unit 4 — Cloud models
### Card 4.1
**Front:** What is a public cloud?
**Back:** Cloud services offered on provider infrastructure that serves multiple customers, with appropriate separation between their resources and data.

### Card 4.2
**Front:** Does “public cloud” mean customer data is publicly visible?
**Back:** No. “Public” describes the deployment model, not unrestricted access to customer data.

### Card 4.3
**Front:** What is a private cloud?
**Back:** A cloud environment dedicated to one organization.

### Card 4.4
**Front:** Is any on-premises server automatically a private cloud?
**Back:** No. A standalone physical server is not automatically a cloud environment.

### Card 4.5
**Front:** What is a hybrid cloud?
**Back:** An integrated combination of private and public cloud environments.

## Unit 5 — Consumption model and Azure hierarchy
### Card 5.1
**Front:** What is the consumption-based model?
**Back:** Charges can be based on measured use of a service according to its pricing rules.

### Card 5.2
**Front:** What is a management group used for in Azure?
**Back:** Organizing subscriptions and applying supported governance across them.

### Card 5.3
**Front:** What is an Azure subscription?
**Back:** A scope for organizing resource deployment, access, policies, quotas, and usage/cost tracking. Billing arrangements depend on the customer's agreement.

### Card 5.4
**Front:** What is a resource group?
**Back:** A logical container that groups related Azure resources for organization and management.

### Card 5.5
**Front:** What is an Azure resource?
**Back:** An individual Azure item, such as a virtual machine, storage account, database, or virtual network.

### Card 5.6
**Front:** What commonly generates Azure service charges?
**Back:** Resources and their usage, priced according to the specific service's billing rules.

### Card 5.7
**Front:** Is Cost Analysis the same as an invoice?
**Back:** No. Cost Analysis helps explore usage and charges; an invoice is a billing document issued according to the billing agreement and period.

### Card 5.8
**Front:** Does deleting a resource erase charges already incurred?
**Back:** No. Deletion may prevent future usage charges, but it does not erase accrued costs.
