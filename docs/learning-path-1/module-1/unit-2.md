# Unit 2: Introduction to cloud computing

**Learning Path 1:** Introduction to Cloud Infrastructure: Describe cloud concepts  
**Module 1:** Describe cloud computing  
**Estimated time:** 3 minutes

## 1. The school has a problem to solve

Imagine a school wants to keep student records digitally: names, classes, marks, attendance and fee balances.

The school wants authorised staff to access the same up-to-date information instead of keeping separate records that may disagree.

One possible solution is to set up a computer that stores the records and runs the school’s application. Other computers can connect to it.

But now the school has another question: **Who will buy, look after and maintain that computer?**

## 2. Two ways to get the job done

### Option A: The school operates its own equipment

The school buys or arranges the equipment, provides a suitable place and power, and takes responsibility for maintaining it and protecting its records.

This gives the school more direct control, but the school also carries more of the equipment-related work.

### Option B: The school uses a cloud provider

Instead of operating all the underlying equipment itself, the school uses computing services supplied by a provider over a network, usually the internet.

Staff can use the school application through their devices, while the provider operates the underlying cloud infrastructure.

The school still has responsibilities, such as deciding who can access student records and using the service securely.

## 3. What has changed?

The school’s need has not changed. It still needs to store records, run an application and let authorised staff access information.

What has changed is **how the school obtains and manages the computing power behind that system**.

Two useful terms describe what the school can obtain:

- **Computing resources:** The underlying capabilities it needs, such as processing power, memory, storage and networking.
- **Computing services:** The useful things made available through those capabilities, such as storing files, running an application or hosting a database.

Think of it this way: resources help make the work possible; services let the school use those capabilities to get something done.

## 4. So, what is cloud computing?

Cloud computing means using computing resources and services provided over a network, usually the internet, instead of having to own and operate all the underlying physical equipment yourself.

The provider operates the cloud infrastructure, while the customer uses the services and remains responsible for the things assigned to them.

One important distinction: **the internet is the connection; cloud computing is the use of computing capabilities and services through that connection.** Simply connecting two computers to Wi-Fi does not automatically mean you are using cloud computing.

## 5. Check your understanding

### Question 1

What makes Option B an example of cloud computing?

A. The school computers are connected to Wi-Fi.  
B. The school uses computing services supplied by a provider over a network.  
C. The school has digitised its student records.

**Correct answer: B.** Cloud computing is about using computing services supplied by a provider—not merely using Wi-Fi.

### Question 2

Which is an example of a computing resource?

A. The school’s attendance report  
B. The school’s student-record application  
C. Storage space used to keep student records

**Correct answer: C.** Storage is a computing resource. An application is software used to do a task.

### Question 3

If the school uses a cloud provider, who is responsible for protecting student records?

A. Only the provider  
B. Only the school  
C. Both have responsibilities, depending on the service and what each manages.

**Correct answer: C.** The provider and school have different responsibilities. We will explore this in the shared responsibility lesson.
