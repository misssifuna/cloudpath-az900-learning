# Module 1 · Unit 2: Introduction to cloud computing

**Learning path:** Introduction to Cloud Infrastructure: Describe cloud concepts  
**Purpose:** Explain what cloud computing is, the problem it addresses, and the foundational concepts.  
**Estimated time:** 5–7 minutes

## 2.1 Start with a school’s on-premises server

Imagine a school keeps its student records in a digital system: names, admission numbers, classes, attendance, marks, and contact details. The school wants authorised staff to use the same up-to-date information.

One option is for the school to own a physical server and keep it on its premises. This is called an **on-premises server**. The server may store the database and run the software staff use.

The school must arrange the physical equipment and its location, electricity, network connection, maintenance, backups, and protection. If the school grows or more people use the system, it may need to upgrade the server or buy additional equipment. If the server fails, the school needs a plan to restore the service and its data.

This setup can work well, but it requires the school—or its IT provider—to plan for and manage the equipment.

## 2.2 What if the school uses a cloud provider instead?

Now imagine the school chooses a cloud service for its student-record system. Instead of buying and operating the physical server itself, the school uses computing resources supplied by a cloud provider, such as Microsoft Azure.

The provider operates the underlying cloud infrastructure in its data centres. The school accesses and uses the service over a network, usually the internet.

The school still needs to manage its own use of the service. For example, it must decide which staff members may view or change student records and protect account credentials. The provider and school have different responsibilities; using the cloud does not mean that the school has no responsibilities.

The important change is **who provides and operates the underlying computing infrastructure**. The school's need—to store and use student records—has not changed.

## 2.3 So, what is cloud computing?

**Cloud computing is the delivery of computing services over the internet.** These services can include servers, storage, databases, networking, software, analytics, and artificial intelligence.

A cloud provider makes computing resources and services available so customers can use what they need without having to own and operate all the underlying physical equipment themselves.

In our school example:

- **On-premises approach:** the school operates a physical server on its own premises, directly or with help from an IT provider.
- **Cloud approach:** the school uses computing services supplied by a cloud provider, which operates the underlying cloud infrastructure.

Both approaches can support digital student records. Cloud computing is an alternative way to obtain and manage the computing capabilities behind the system.

## 2.4 Computing resources and computing services

To understand cloud computing, distinguish between a **resource** and a **service**.

**Computing resources** are the underlying capabilities needed to run digital systems:

- **Processing power:** carries out instructions.
- **Memory:** provides working space while programs run.
- **Storage:** keeps files and data.
- **Networking:** connects systems so they can communicate.

A **computing service** makes computing capability available for a useful task. Examples include hosting an application, storing files, running a database, or providing access to software.

In the school example, storage capacity is a resource. A database or file-storage service gives the school a way to store and use records.

## 2.5 Cloud computing is more than an internet connection

The internet is the network through which a customer can reach cloud services. Cloud computing is the use of computing capabilities and services delivered over that network.

Connecting a school computer to Wi-Fi does not, by itself, mean the school is using cloud computing. The school uses cloud computing when it accesses a computing service supplied by a cloud provider.

## 2.6 What problem does cloud computing address?

Cloud computing can help organizations use computing capacity without having to buy and operate all the physical infrastructure themselves.

The school example gives us a starting point for understanding several benefits that we will explore more fully later:

- **Less upfront equipment spending:** the school may not need to buy its own physical servers.
- **Faster provisioning:** supported cloud resources can often be set up faster than purchasing and installing new equipment.
- **Flexible capacity:** resources can often be increased or reduced as needs change.
- **Provider-operated infrastructure:** the cloud provider manages the physical data-centre equipment and certain service layers.

Cloud services still cost money, and availability or performance depends on the chosen service and configuration. The school must also protect its accounts and information and understand which responsibilities remain with it.

## 2.7 How this school example will help in later units

We will keep using the same school scenario to connect the cloud concepts across this learning path:

- **Benefits of cloud services:** compare the effort of maintaining on-premises equipment with using cloud resources.
- **Shared responsibility model:** identify what the provider manages and what the school must still manage.
- **Cloud models:** explore public, private, and hybrid cloud arrangements.
- **Consumption-based model:** understand how the school's use of cloud resources can affect its bill.

These are previews, not the full explanations. Each later unit will develop its topic separately.

## 2.8 Check your understanding

**Question 1.** What does *on-premises server* mean in our example?

A. A physical server the school keeps and operates on its premises.  
B. Any computer connected to Wi-Fi.  
C. A server that can never connect to the internet.

**Correct answer: A.** On-premises means the equipment is located at the school's own site and is operated by the school or its IT provider.

**Question 2.** Which statement best describes cloud computing?

A. Buying a server for the school's computer room.  
B. Using computing services delivered over the internet.  
C. Connecting two computers to the same Wi-Fi network.

**Correct answer: B.** Cloud computing is about using computing services delivered over a network, usually the internet.

**Question 3.** In the cloud approach, who operates the underlying physical cloud infrastructure?

A. Always the school alone.  
B. The cloud provider, while the school retains responsibilities for its use of the service.  
C. Every student who uses the system.

**Correct answer: B.** The provider operates the underlying cloud infrastructure; the customer still has responsibilities depending on the service.

**Question 4.** Which is a computing resource?

A. Storage capacity.  
B. A school's decision to enrol a student.  
C. A printed attendance report.

**Correct answer: A.** Storage capacity is an underlying computing resource.

**Question 5.** Does moving to cloud services mean the school has no security responsibilities?

**Suggested answer:** No. The provider and school have different responsibilities. The school must still manage the responsibilities assigned to it, such as user access and account security.

## Key takeaway

A school can run a system using an on-premises server or use computing services supplied by a cloud provider. **Cloud computing means using computing services delivered over the internet, rather than having to own and operate all the underlying physical infrastructure yourself.**

We will reuse this school example in later units to understand cloud benefits, shared responsibility, cloud models, and consumption-based costs.
