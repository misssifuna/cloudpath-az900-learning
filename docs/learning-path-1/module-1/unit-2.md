# Module 1 · Unit 2: Introduction to cloud computing

**Learning path:** Introduction to Cloud Infrastructure: Describe cloud concepts  
**Purpose:** Explain what cloud computing is, the problem it addresses, and the foundational concepts.  
**Estimated time:** 5–7 minutes

## 2.1 Start with the problem

Imagine you run a small online shop in Kenya. You need a website, somewhere to store product photos and order records, and enough computing capacity for customers to browse and place orders.

You could buy and operate your own servers. But then you would need to arrange the equipment, power, physical security, maintenance, backups, and upgrades. You would also need to estimate how much capacity to buy before knowing exactly how many customers you will have.

There is another option: use computing services supplied by a cloud provider.

## 2.2 What is cloud computing?

**Cloud computing is the delivery of computing services over the internet.** These services can include servers, storage, databases, networking, software, analytics, and artificial intelligence.

Instead of owning and managing all the underlying physical equipment, a customer can access resources provided by a cloud provider and configure or use the services needed.

For example, the online shop could host its website and store its product images using cloud services. Customers visit the website over the internet; the shop owner manages the application and business information, while the cloud provider operates the underlying cloud infrastructure.

The exact division of work depends on the service selected. Cloud computing does not automatically remove every customer responsibility.

## 2.3 What problem does cloud computing address?

Cloud computing can help organizations obtain computing capacity without having to purchase and operate all the physical infrastructure themselves.

Common benefits include:

- **Less upfront infrastructure spending:** use provider-operated resources instead of buying every server before starting.
- **Faster setup:** provision supported resources when needed rather than waiting to purchase and install physical equipment.
- **Flexible capacity:** increase or reduce resources as demand changes, where the service supports it.
- **Access over a network:** users and applications can reach services from connected locations, subject to network access and security controls.
- **Provider-managed infrastructure:** the provider operates the physical data-centre equipment and certain layers of the service.

Cloud computing still has costs and risks. Customers must choose appropriate services, protect their accounts and data, manage access, and monitor usage and charges.

## 2.4 Cloud computing is more than an internet connection

The internet is the network connection. Cloud computing is the use of computing services delivered through that network.

Connecting a laptop to Wi-Fi does not by itself mean cloud computing is being used. Visiting an online service that stores files, hosts an application, or provides computing capacity can be an example of using cloud services.

## 2.5 Computing resources and computing services

**Computing resources** are the underlying capabilities used to run digital systems:

- **Processing power:** carries out instructions.
- **Memory:** provides working space while programs run.
- **Storage:** keeps files and data.
- **Networking:** connects systems so they can communicate.

A **computing service** makes computing capability available for a useful task. Examples include hosting a website, storing files, running a database, or providing an application.

A useful distinction: storage capacity is a resource; a file-storage service is a way to use storage to meet a need.

## 2.6 How cloud computing works at a high level

1. A customer selects a cloud service that meets a need.
2. The customer configures the service and access permissions.
3. The provider supplies and operates the underlying cloud infrastructure.
4. The customer uses the service over a network and manages the responsibilities assigned to them.
5. Usage may be measured for billing, depending on the service and pricing arrangement.

The next units explore three related questions: who is responsible for each part, how cloud environments are organized, and how usage can translate into cost.

## 2.7 Check your understanding

**Question 1.** Which statement best describes cloud computing?

A. Using Wi-Fi to connect two devices.  
B. Using computing services delivered over the internet.  
C. Buying a more powerful laptop.

**Correct answer: B.** Cloud computing involves using computing services delivered over a network, usually the internet.

**Question 2.** Which is a computing resource?

A. Storage capacity.  
B. A completed sales report.  
C. A business decision.

**Correct answer: A.** Storage capacity is a resource used to keep data.

**Question 3.** What is one reason a small online shop might use cloud services?

A. It removes every security responsibility from the shop.  
B. It guarantees that service use will always be free.  
C. It can use provider-operated infrastructure without buying all the underlying equipment.

**Correct answer: C.** Cloud services can reduce the need to purchase and operate all physical infrastructure. They do not eliminate costs or customer responsibilities.

**Question 4.** Does connecting a computer to Wi-Fi automatically mean it is using cloud computing?

A. Yes, every Wi-Fi connection is cloud computing.  
B. No; Wi-Fi is a connection, while cloud computing is the use of computing services over a network.

**Correct answer: B.** The connection alone is not the cloud service.

**Question 5.** What is the difference between a computing resource and a computing service?

**Suggested answer:** A resource is an underlying capability, such as processing power or storage. A service makes capabilities available for a task, such as hosting a website or storing files.

## Key takeaway

Cloud computing lets customers use computing services delivered over a network rather than having to own and operate all the physical infrastructure themselves. It can offer flexibility and faster access to capacity, but customers still need to manage their own responsibilities and costs.
