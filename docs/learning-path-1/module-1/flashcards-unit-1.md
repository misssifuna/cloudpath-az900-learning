## Key terms

| Front — prompt | Back — answer |
|---|---|
| What is cloud computing? | Using computing resources and services over a network, usually the internet. |
| Who is a cloud provider? | An organization that supplies cloud services, such as Microsoft. |
| Who is a cloud customer? | A person or organization that uses cloud services. |
| What is a cloud resource? | A usable component, such as a virtual machine, database, or storage account. |
| What is infrastructure? | The underlying computing, storage, networking, and related systems. |
| What does consumption mean in cloud computing? | The amount of a cloud resource or service used. |
| What is Microsoft Azure? | Microsoft's cloud platform for computing, storage, networking, databases, AI, and more. |
