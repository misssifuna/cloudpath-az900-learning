# Module 1 · Unit 1: Introduction to Microsoft Azure Fundamentals

**Learning path:** Introduction to Cloud Infrastructure: Describe cloud concepts  
**Purpose:** Establish the technical context, terminology, and overall module roadmap.  
**Estimated time:** 3 minutes

## 1.1 Welcome to Microsoft Azure Fundamentals

Microsoft Azure Fundamentals introduces the basic concepts behind cloud computing and explains how Microsoft Azure provides computing services to individuals, businesses, and organizations.

Before studying individual Azure services, we need to understand what cloud computing means, why it is useful, how responsibilities are divided, and how cloud usage is charged.

## 1.3 What is Microsoft Azure?

Microsoft Azure is Microsoft's cloud computing platform. It provides services for computing, storage, networking, databases, analytics, artificial intelligence, and security.

Organizations can use Azure to build, deploy, and manage applications and infrastructure without necessarily owning and maintaining all the physical equipment behind those services.
