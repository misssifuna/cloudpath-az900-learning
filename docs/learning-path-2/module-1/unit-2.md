# Learning Path 2 · Module 1 · Unit 2: What is Microsoft Azure?

**Learning path:** Introduction to Cloud Infrastructure: Describe Azure architecture and services  
**Purpose:** Explain what Azure is and recognise the broad categories of services it provides.  
**Estimated time:** 5–7 minutes

## 2.1 A school’s technology needs

Imagine a school in Saboti wants a website, an online student-record system, and a secure way for teachers to access files.

The school could buy and maintain its own physical servers. It would need to arrange equipment, a secure location, electricity, connectivity, maintenance, and protection.

Alternatively, it can use cloud services. Microsoft Azure is Microsoft's cloud computing platform, offering services that organisations can use to build, run, store, secure, and manage applications and data without owning every underlying server and piece of infrastructure themselves.

Azure does not remove every responsibility from the school. The school still manages its users, data, application settings, and other duties according to the service it chooses.

## 2.2 What does Azure provide?

Azure is a platform made up of many services, not one single application.

- **Compute:** processing power to run applications and workloads.
- **Storage:** services for files, images, backups, and other data.
- **Networking:** connections that let applications and services communicate.
- **Databases:** services for storing and querying information.
- **Identity and security:** tools to control sign-in and access.

These categories are introduced here and explored in later modules.

## 2.3 Three important ideas

### Cloud platform
Azure offers a collection of related services that organisations can select to meet different needs.

### Consumption and cost
Many Azure services charge according to usage, configuration, or pricing rules. Creating a resource can incur charges even if nobody is actively using it. Always check the pricing details before deploying resources.

### Shared responsibility
Microsoft manages parts of the cloud infrastructure, but customers retain responsibilities. The exact division depends on the service and configuration.

## 2.4 School-based example

A school might use Azure to host its public website, store approved documents, and run an application used by staff. It chooses the services it needs and manages access to its own data. It should also plan for cost, security, backups, and continuity.

## 2.5 Knowledge check

**Question 1:** What is Microsoft Azure?

A. A single word-processing application  
B. Microsoft's cloud computing platform offering a range of services  
C. A physical server that every customer must buy  
D. A programming language

**Correct answer:** B.

**Explanation:** Azure is a cloud platform containing services for compute, storage, networking, databases, identity, and more.

**Question 2:** If a school uses Azure, does Microsoft automatically take over every security responsibility?

A. Yes, all responsibility transfers to Microsoft  
B. No, responsibility is shared and depends on the service

**Correct answer:** B.

**Explanation:** Microsoft manages parts of the underlying cloud infrastructure. The customer still has responsibilities, including appropriate access controls and protection of its data.

## 2.6 Key takeaways

- Azure is Microsoft's cloud computing platform.
- Azure provides many different services.
- Customers choose services according to their needs.
- Usage and configuration can affect cost.
- Using Azure does not remove all customer responsibilities.
