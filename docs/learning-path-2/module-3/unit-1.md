# Learning Path 2 — Module 3, Unit 1: Introduction to Azure networking services

**Learning path:** Introduction to Cloud Infrastructure — Describe Azure architecture and services  
**Module:** Describe Azure networking services

## Welcome

Azure networking connects resources to each other, to on-premises systems, and to users or applications over networks. Networking choices influence reachability, security, performance, and how an organization connects its existing infrastructure to Azure.

## What this module covers

- Azure virtual networking, including virtual networks and subnets
- Azure virtual private networks and VPN Gateway
- Azure ExpressRoute for private connectivity
- Azure DNS for name resolution

The supplied Badge Links notes list “Create, configure, and manage users” as Unit 2 in this networking module. That title does not match the current Microsoft Learn networking module, which lists **Describe Azure virtual networking**. CloudPath uses the verified networking topic for Unit 2 and records the discrepancy in the syllabus reference instead of teaching user administration as networking.

## Quick knowledge check

**What is the main purpose of Azure networking services?**

**Answer:** To connect resources and systems while managing how they communicate and how that communication is secured.
