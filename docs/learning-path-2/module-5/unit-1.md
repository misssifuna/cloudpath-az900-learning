# Learning Path 2 — Module 5, Unit 1: Introduction to Azure identity, access, and security

**Learning path:** Introduction to Cloud Infrastructure — Describe Azure architecture and services  
**Module:** Describe Azure identity, access, and security

## Welcome

Cloud resources need to be protected so that the right people and systems can access the right information in the right way. Azure identity, access, and security features help organizations establish identities, verify sign-ins, grant permissions, and reduce security risks.

## What this module covers

1. Azure directory services
2. Authentication methods
3. External identities
4. Conditional Access
5. Azure role-based access control (RBAC)
6. Zero Trust
7. Defense in depth
8. Encryption and key management
9. Microsoft Defender for Cloud

## A familiar example

A school portal may need to let teachers sign in, allow a visiting auditor temporary access, limit each staff member to appropriate records, protect stored student information, and detect security risks. These are related but different problems, so Azure provides different identity and security capabilities.

## Quick knowledge check

**Does proving who you are automatically mean you have permission to change every Azure resource?**

**Answer:** No. Authentication verifies identity; authorization determines what that identity can do.

## Key takeaway

Identity, authentication, authorization, and security controls work together, but each has a distinct role.
