## Scope alignment

These custom modules organize study content around the **Describe Azure architecture and services** domain of the AZ-900 exam. That official domain includes core architectural components, compute and networking, storage, and identity/access/security. Microsoft's current study guide remains the authority for exam scope and may change independently of this repository.

Topics to cross-check against the official guide include:
- Core components: regions, region pairs, sovereign regions, availability zones, datacenters, resources, resource groups, subscriptions, and management groups.
- Compute and networking: virtual machines, containers, functions, Virtual Machine Scale Sets, availability sets, Azure Virtual Desktop, application hosting, virtual networks, subnets, peering, DNS, VPN Gateway, ExpressRoute, and public/private endpoints.
- Storage: storage services, tiers, redundancy, account options, file transfer, and migration options.
- Identity, access, and security: Microsoft Entra ID and Domain Services, SSO, MFA, passwordless, external identities, Conditional Access, RBAC, Zero Trust, defense in depth, and Microsoft Defender for Cloud.

**Important:** A listed lesson is evidence that the topic has a place in the learning sequence, not proof that every official exam bullet has been fully covered. Use the current study guide below to track any gaps.
