# Learning Path 3 — Module 2, Unit 1: Introduction to Azure governance and compliance

**Module:** Describe features and tools in Azure for governance and compliance  
**Learning goal:** Understand why organizations apply rules, protect resources, and demonstrate compliance.

Governance helps an organization keep its Azure environment aligned with its requirements. Compliance involves meeting applicable standards, policies, and obligations. Azure provides tools for understanding data, enforcing resource rules, preventing accidental changes, and reviewing trust and compliance information.

This module introduces Microsoft Purview, Azure Policy, resource locks, and the Service Trust Portal.

## Quick knowledge check
**Why use governance tools?**

**Answer:** To help ensure resources are organized, compliant, protected, and managed consistently.
