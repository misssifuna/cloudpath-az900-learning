# Learning Path 3 — Module 4, Unit 1: Introduction to Azure monitoring tools

**Module:** Describe monitoring tools in Azure  
**Learning goal:** Understand why cloud resources and applications need monitoring, recommendations, and health information.

Azure monitoring helps teams understand resource behavior, detect issues, and make informed operational decisions. Different tools answer different questions: what could be improved, whether Azure has a service issue, and what is happening inside a resource or application.

This module covers Azure Advisor, Azure Service Health, and Azure Monitor with its related capabilities.

## Quick knowledge check
**Why might an organization use more than one monitoring tool?**

**Answer:** Tools serve different purposes, such as recommendations, platform health, metrics, logs, alerts, and application diagnostics.
