# Learning Path 3 — Module 1, Unit 1: Introduction to Azure cost management

**Module:** Describe cost management in Azure  
**Learning goal:** Understand why cloud costs need to be estimated, monitored, and managed.

Cloud resources can incur charges based on what you provision and how you use it. Cost management helps organizations plan spending, understand actual usage, and identify opportunities to reduce unnecessary costs.

In this module, you will learn about cost factors, the Azure Pricing Calculator, Microsoft Cost Management, resource tags, and optimization options.

A school website may use compute, storage, networking, and databases. The total cost depends on the selected services, their configuration, usage, and region—not simply on the number of websites.

## Quick knowledge check
**Why should an organization monitor cloud costs?**

**Answer:** To compare spending with expectations, detect unexpected usage, and make informed optimization decisions.
