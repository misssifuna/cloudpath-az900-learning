# Learning Path 3 — Module 3, Unit 1: Introduction to Azure management and deployment tools

**Module:** Describe features and tools for managing and deploying Azure resources  
**Learning goal:** Understand the main ways to interact with Azure and deploy resources consistently.

Azure resources can be managed through a graphical portal, command-line tools, APIs, and templates. Different tools suit different tasks, but they work with the same Azure resource management platform.

This module covers the Azure portal, Cloud Shell, CLI and PowerShell, Azure Arc, Azure Resource Manager, and infrastructure as code.

## Quick knowledge check
**Why are there several Azure management tools?**

**Answer:** Different users and workflows need graphical, command-line, automation, or consistent deployment approaches.
