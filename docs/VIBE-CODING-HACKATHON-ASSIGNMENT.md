# Vibe Coding Hackathon: AZ-900 Exam Prep Edition

## For the #1MillionDevs Movement

### Overview

Learners preparing for Microsoft Azure Fundamentals (AZ-900) are invited to turn their learning experience into a tool that helps others prepare more effectively. Use AI-assisted and low-code tools to build exam-preparation experiences that make studying smarter, easier, and more engaging.

**Hackathon theme:** “Building Smarter Exam Prep Tools from Our Own Learning Journey.”

The goal is to help learners become builders and create useful tools for the next cohort.

## Problem statements and challenges

### 1. Practice and assessment — Smart Quiz Builder
**Problem:** Learners practise questions but do not always understand why an answer is right or wrong.

**Challenge:** Build a quiz app that gives instant feedback and clear explanations for every answer, organised by AZ-900 topic.

### 2. Memory and revision — Flashcard Coach
**Problem:** Learners struggle to remember Azure terms, services, and concepts.

**Challenge:** Create a flashcard or spaced-repetition tool that helps learners revise key concepts and focuses on the ones they keep getting wrong.

### 3. Planning — Personal Study Planner
**Problem:** Learners do not know how to plan their study time before an exam date.

**Challenge:** Build a tool that creates a study plan based on the learner's exam date, available hours, and weak areas.

### 4. Support — AI Study Buddy
**Problem:** Cloud concepts can feel abstract, especially for beginners.

**Challenge:** Develop an AI assistant that explains Azure concepts in simple terms, using real-life African examples or local languages.

### 5. Progress — Readiness Tracker
**Problem:** Learners often do not know whether they are ready to sit the exam.

**Challenge:** Create a dashboard that tracks practice scores by topic and shows how ready a learner is.

## CloudPath project alignment notes

CloudPath AZ-900 Learning Companion is an unofficial, learner-built study aid. Its planned features align with the challenge through:
- A roadmap covering all three AZ-900 learning paths
- Original practice questions with explanations
- Flashcards and revision support
- A readiness dashboard based on learner activity
- A plain-language tutor using relatable examples

The prototype's current tutor responses are prepared examples, not a live AI integration. Progress is stored in the current browser only. Describe these limitations accurately during the demo and presentation.
